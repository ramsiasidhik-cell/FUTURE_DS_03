## Overview
This project analyzes a real-world bank marketing campaign dataset to understand how customers move through a marketing funnel, identify drop-off points, and compare channel performance — with actionable recommendations to improve conversions.

## Key Findings
- **Overall conversion rate:** 11.70% (5,289 out of 45,211 contacts)
- **Best channel:** Cellular (14.9% conversion rate)
- **Best month:** March (51% conversion rate)
- **Best segment:** Students (29%) and Retired (23%)
- **Worst period:** May–August (below 7%)
